# ZEPHYR — социальная сеть

Современная социальная сеть на Next.js 16, React 19, TailwindCSS v4, Prisma и NextAuth v5.

## Стек

- **Фреймворк:** Next.js 16.2.10 (App Router, Turbopack)
- **UI:** React 19.2.4, TailwindCSS v4, lucide-react
- **База данных:** PostgreSQL + Prisma ORM
- **Аутентификация:** NextAuth v5 (bcrypt, AES-256-GCM для email)
- **Валидация:** Zod
- **Контейнеризация:** Docker (multi-stage), docker-compose

---

## Требования к окружению

- Node.js 20+
- PostgreSQL 15+
- npm / yarn / pnpm / bun
- Docker (опционально)

## Переменные окружения

```env
# База данных
DATABASE_URL=postgresql://user:password@localhost:5432/zephyr

# NextAuth
AUTH_SECRET=your-secret-here
AUTH_URL=http://localhost:3000

# Email (SMTP)
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=user@example.com
SMTP_PASS=password

# Шифрование email
ENCRYPTION_KEY=your-32-byte-hex-key

# Загрузка файлов
UPLOAD_DIR=./uploads
```

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Генерация Prisma клиента
npx prisma generate

# Миграция БД
npx prisma migrate dev

# Запуск dev-сервера
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Docker

```bash
docker compose up -d
```

Миграции накатываются автоматически при старте контейнера (`prisma migrate deploy` в `docker-entrypoint.sh`).

### Мессенджер
Полноценный чат между пользователями с поддержкой Socket.IO для real-time общения.

**Компоненты:**
- **`ChatView.tsx`** — окно чата с сообщениями, индикатором печатания, fallback на polling
- **`MessageBubble.tsx`** — пузырёк сообщения со стилями `message-sent` / `message-received`
- **`MessageInput.tsx`** — поле ввода с отправкой по Enter и кнопкой
- **`ConversationList.tsx`** — список диалогов с поиском и счётчиком непрочитанных
- **`NewChatModal.tsx`** — создание нового чата (личного или группового) с поиском пользователей

**API:**
- `/api/messenger/conversations` — CRUD диалогов
- `/api/messenger/conversations/[id]/messages` — сообщения
- `/api/messenger/conversations/[id]/typing` — индикатор печати
- `/api/messenger/users` — поиск пользователей для чата
- `/api/messenger/unread` — счётчик непрочитанных

**Real-time:**
- `socket-server.ts` — серверная часть (регистрация, комнаты, `message:send`, typing, heartbeat)
- `socket-client.ts` — клиентский хук `useSocket`
- `server.ts` — custom Next.js сервер с Socket.IO
- Интеграция Socket.IO в ChatView с fallback на polling при потере соединения

## Zephyr — Update Release 0.0.6

### Мессенджер — улучшения и доработки

Фундаментальная доработка мессенджера по результатам ревью: исправлены архитектурные проблемы, добавлены недостающие функции, написаны тесты.

**Схема Prisma:**
- **`MessageEditHistory`** — модель для истории редактирований сообщений
- **`MessageDeliveryStatus`** — статусы доставки и прочтения (per-участник)
- **`PinnedMessage`** — закреплённые сообщения в чате
- **`UserBlock`** — блокировка пользователей
- **`ConversationParticipant`** — новые поля: `archivedAt`, `mutedUntil`, `draftContent`, `pinnedAt`

**API:**
- **`messages/[messageId]` (PATCH)** — редактирование с сохранением истории в `MessageEditHistory`
- **`messages/[messageId]` (DELETE)** — удаление с режимами `forMe` (скрыть у себя) и `forEveryone` (удалить для всех)
- **`conversations/[id]/messages` (GET)** — возвращает `forwardFrom`, `deliveryStatuses`, `pinnedMessages`
- **`conversations/[id]` (PATCH)** — обновление названия/типа чата
- **`conversations/[id]` (DELETE)** — выход из чата (`leave`) или удаление (`delete`)
- **`conversations` (GET)** — сортировка: закреплённые чаты сверху, затем по `lastMessageAt`

**Компоненты:**
- **`ChatView.tsx`** — пагинация (cursor-based, 50 сообщений), виртуализация списка (react-window), оптимистичный UI с tempId, retry при ошибке, индикатор подключения, разделители дат, unread divider, кнопка scroll-to-bottom, бесконечный скролл
- **`MessageBubble.tsx`** — read receipts (одна/две галочки, синие — прочитано), forwarded badge, edited, контекстное меню (long-press на мобильных), delete for me/everyone
- **`ConversationList.tsx`** — сортировка закреплённых чатов сверху, флаг `isPinned`
