### 1.2 Проблемы производительности ленты

| # | Проблема | Файл | Описание |
|---|----------|------|----------|
| 1 | **For-you загружает ВСЕ посты в память** | `src/app/api/feed/for-you/route.ts:27-67` | `prisma.post.findMany()` без `skip/take`, все посты загружаются, сортируются по скорингу, потом пагинируются `slice()`. При 100k+ постах — OOM |

| 3 | **Нет debounce на loadMore** | `src/app/feed/page.tsx:93-97` | `handleLoadMore` вызывается без debounce, можно заспамить API |
| 4 | **feedTab — useState с константой** | `src/app/feed/page.tsx:35` | `useState<FeedTab>('for-you')` никогда не меняется, можно заменить на обычную переменную |

## 3. Архитектурные проблемы

| # | Проблема | Описание | Влияние |
|---|----------|----------|---------|
| 1 | **For-you лента без БД-пагинации** | Все посты загружаются в память, сортируются, потом пагинируются | Критическое — OOM при 100k+ постов |
| 2 | **Нет кэширования** | Ни лента, ни сообщения не кэшируются | Избыточные запросы к БД |
| 3 | **Нет очередей задач** | Нет Bull/Redis для фоновых задач | Блокирующие операции в request-response цикле |
| 4 | **Нет CDN для медиа** | Медиа хранятся и отдаются с сервера | Нагрузка на сервер |
| 5 | **Нет Web Push уведомлений** | Нет push-уведомлений о новых сообщениях | Пользователь не узнаёт о сообщениях вне сайта |
| 6 | **Нет WebRTC** | Нет P2P для звонков/видео | Нельзя реализовать звонки |
| 7 | **Нет IndexedDB кэша** | Сообщения не кэшируются на клиенте | Офлайн не работает |

## 4. Безопасность

| # | Проблема | Описание |
|---|----------|----------|
| 1 | **Шифрование только на сервере** | AES-256-GCM на сервере, но не E2EE | Администратор БД может читать сообщения |
| 2 | **Дезинформация о E2EE** | В UI указано "сквозное шифрование" | Пользователи misled о реальной безопасности |
| 3 | **Поиск по зашифрованным данным** | `searchContent` хранит plaintext для поиска | Компрометация шифрования через побочный канал |
| 4 | **Нет CSP заголовков** | Content Security Policy не настроена | XSS уязвимости |
| 5 | ~~**Нет rate limiting на отправку сообщений**~~ | ~~Можно спамить сообщениями~~ | ~~DoS уязвимость~~ ✅ **ИСПРАВЛЕНО** |
